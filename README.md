# Segmentación de Clientes (RFM)

Proyecto de clustering listo para Google Colab. Incluye EDA, Elbow, Silhouette y K-Means.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/segmentacion-rfm/blob/main/segmentacion_rfm_colab.ipynb)

## Contenido

- Simulación de datos RFM
- EDA (histogramas, pairplot)
- Elbow + Silhouette para elegir k
- K-Means final
- Visualización de clusters
- Perfil de segmentos
- Conclusiones

Dataset: datos simulados RFM
